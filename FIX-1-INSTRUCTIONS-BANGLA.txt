============================================================
TechPilot AI - সংশোধনী ১: সুরক্ষা ও কনফিগ ঠিক করা (কাজ ৮, ৯, ১০)
============================================================

এই জিপে যা আছে (৬টি ফাইল + এই নির্দেশনা):
------------------------------------------------------------
1) backend/.env            -> নতুন শক্তিশালী JWT_SECRET + CORS_ORIGIN
2) backend/.env.example    -> সম্পূর্ণ টেমপ্লেট, বাংলা ব্যাখ্যাসহ (নতুন ফাইল)
3) backend/src/server.js   -> দুর্বল JWT_SECRET হলে সার্ভার চালু হবেই না
4) backend/src/app.js      -> CORS এখন শুধু নিজের ফ্রন্টএন্ডকে ঢুকতে দেয়
5) .env (রুট ফোল্ডারে)      -> docker-compose এর জন্য একই নতুন JWT_SECRET
6) .env.example (রুটে)     -> docker-compose এর টেমপ্লেট (নতুন ফাইল)

কী সমস্যা ছিল?
------------------------------------------------------------
- JWT_SECRET ছিল একটা বাংলা "placeholder" লেখা। এটা সবাই দেখতে পায়,
  তাই দূরের কেউ নিজে নিজে ভুয়া লগইন-টোকেন বানিয়ে আপনার API ঢুকতে পারত।
- CORS পুরো খোলা ছিল: ইন্টারনেটের যেকোনো ওয়েবসাইট আপনার ব্যাকএন্ডে অনুরোধ
  পাঠাতে পারত।
- .env.example এ শুধু PORT=5000 ছিল; নতুন কেউ প্রজেক্ট সেটআপ করতে গেলে
  বুঝতো না কোন কোন ভেরিয়েবল দরকার।

ইনস্টল করার নিয়ম (ধাপে ধাপে)
------------------------------------------------------------
ধাপ ১: আপনার পুরো প্রজেক্ট ফোল্ডারের একটা কপি ব্যাকআপ হিসেবে রাখুন।
        (ফোল্ডারে রাইট-ক্লিক -> Copy -> Paste)

ধাপ ২: এই জিপটি আনজিপ করুন। ভেতরে উপরের ৬টি ফাইল ফোল্ডার-কাঠামোসহ পাবেন।

ধাপ ৩: জিপের ভেতরের "backend" ফোল্ডার আর দুটি .env ফাইল আপনার প্রজেক্টের
        রুট ফোল্ডারে (যেখানে docker-compose.yml আছে, যেমন E:\techpilot-ai\techpilot-ai)
        কপি-পেস্ট করুন।
        -> জিজ্ঞেস করলে "Replace the files in the destination" বাছুন।

ধাপ ৪: ব্যাকএন্ড চালু থাকলে টার্মিনালে Ctrl+C চেপে বন্ধ করুন।

চালানো ও টেস্ট করার নিয়ম
------------------------------------------------------------
টেস্ট ১ (ব্যাকএন্ড চালু):
  টার্মিনাল/PowerShell খুলে লিখুন:
      cd E:\techpilot-ai\techpilot-ai\backend
      npm run dev

  সফল হলে দেখবেন:
      TechPilot AI backend listening on port 5000
      JWT_SECRET security check: OK
      Database connection successful: ...

টেস্ট ২ (ফ্রন্টএন্ড + লগইন):
  নতুন একটা টার্মিনাল খুলে:
      cd E:\techpilot-ai\techpilot-ai\frontend
      npm run dev

  তারপর ব্রাউজারে http://localhost:5173 খুলুন।
  - আগের লগইন এখন আর কাজ করবে না (কারণ সিক্রেট বদলেছে)।
  - আবার লগইন করুন। লগইন সফল হলেই প্রমাণ যে নতুন secret ঠিকমতো কাজ করছে।
  - Dashboard / Projects / Diagnose — সব আগের মতোই চলবে।

টেস্ট ৩ (ঐচ্ছিক, নিরাপত্তা-চেক দেখতে চাইলে):
  backend/.env খুলে JWT_SECRET এর মান মুছে "abc" লিখে সেভ করুন,
  তারপর npm run dev চালান। সার্ভার চালু হবে না, বড় করে
  "SECURITY ERROR" দেখাবে। এটাই আমাদের নতুন নিরাপত্তা-রক্ষী।
  টেস্ট শেষে আগের লম্বা secret টা আবার বসিয়ে দিন।

Docker দিয়ে চালালে:
      docker compose down
      docker compose up -d --build
  (রুট .env এ একই নতুন JWT_SECRET দেওয়া আছে, তাই Docker ও নিরাপদ।)

সতর্কতা
------------------------------------------------------------
- backend/.env এ এখন আসল সিক্রেট আছে। ভবিষ্যতে কাউকে প্রজেক্ট শেয়ার
  করলে এই ফাইলটা বাদ দিয়ে দিন, বদলে backend/.env.example কপি করে দিন।
- আপনার ডাটাবেস পাসওয়ার্ড (Postgres@1234) অপরিবর্তিত আছে, তাই
  ডাটাবেস কানেকশনে কোনো সমস্যা হবে না।
- কোনো সমস্যা হলে ব্যাকআপ ফোল্ডার থেকে পুরনো ফাইলগুলো ফেরত এনে
  আমাকে জানান — পরের জিপে ঠিক করে দেব।

পরের সংশোধনী (জিপ ২): ডায়াগনোসিস এজেন্টে RAG (নলেজ বেস) যুক্ত করা —
যাতে AI উত্তর দেওয়ার সময় আপনার আপলোড করা জ্ঞান-ডকুমেন্ট থেকে তথ্য ব্যবহার করে।
