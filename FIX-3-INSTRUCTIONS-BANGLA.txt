============================================================
TechPilot AI - সংশোধনী ৩: স্ক্রিনশট দিয়ে ডায়াগনোসিস (কাজ ১ ও ৩)
============================================================

এই জিপে যা আছে (৫টি ফাইল + এই নির্দেশনা) — সবই frontend এর:
------------------------------------------------------------
1) src/pages/VisualDiagnose.jsx   -> নতুন পেজ: স্ক্রিনশট আপলোড করে AI দিয়ে
                                     বিশ্লেষণ (নতুন ফাইল)
2) src/api/client.js              -> API ক্লায়েন্টে ফাইল আপলোড (FormData) সাপোর্ট
3) src/App.jsx                    -> নতুন পেজের রাউট (/visual)
4) src/components/Layout.jsx      -> সাইডবারে নতুন লিংক "Visual Diagnose"
5) src/App.css                    -> নতুন পেজের স্টাইল (প্রিভিউ ইমেজ ইত্যাদি)

ব্যাকএন্ডে কোনো পরিবর্তন নেই — ব্যাকএন্ড রিস্টার্ট করা লাগবে না।

এর আগে কী সমস্যা ছিল?
------------------------------------------------------------
- ব্যাকএন্ডে স্ক্রিনশট বিশ্লেষণের (Visual Agent) সবকিছু তৈরি ছিল,
  কিন্তু ওয়েবসাইটে দেখানোর কোনো পেজই ছিল না।
- ফ্রন্টএন্ডের API ক্লায়েন্ট শুধু JSON পাঠাতে পারত, ফাইল আপলোড
  করতেই পারত না — তাই ইমেজ পেজ বানানো অসম্ভব ছিল।

ইনস্টল করার নিয়ম (ধাপে ধাপে)
------------------------------------------------------------
ধাপ ১: পুরো প্রজেক্ট ফোল্ডারের একটা কপি ব্যাকআপ রাখুন।

ধাপ ২: জিপ আনজিপ করুন। ভেতরের "frontend" ফোল্ডারটা আপনার প্রজেক্ট
        রুটে (যেমন E:\techpilot-ai\techpilot-ai) কপি-পেস্ট করুন।
        -> "Replace the files in the destination" বাছুন।

ধাপ ৩: ফ্রন্টএন্ড চালু থাকলে বন্ধ করুন (Ctrl+C)।

চালানো ও টেস্ট করার নিয়ম
------------------------------------------------------------
টেস্ট ১ (নতুন পেজ এসেছে কিনা):
  ফ্রন্টএন্ড চালু করুন:
      cd E:\techpilot-ai\techpilot-ai\frontend
      npm run dev

  লগইন করে দেখুন — সাইডবারে নতুন লিংক "Visual Diagnose" থাকবে
  (Diagnose এর ঠিক নিচে)। ক্লিক করলে স্ক্রিনশট আপলোড পেজ আসবে।

টেস্ট ২ (ভুল ফাইল হলে বন্ধুত্বপূর্ণ error):
  কোনো PDF/ZIP ফাইল বাছাই করার চেষ্টা করুন —
  "Please choose an image file..." error দেখাবে।

টেস্ট ৩ (আসল AI বিশ্লেষণ):
  ১) ভিশন মডেল আছে কিনা দেখুন:  ollama list
     তালিকায় llava না থাকলে:  ollama pull llava:latest
     (প্রায় ৪.৭ GB ডাউনলোড হবে, একটু সময় লাগবে)
  ২) যেকোনো error-এর স্ক্রিনশট নিন (যেমন: কোনো প্রোগ্রামের error
     popup এর ছবি নিয়ে PrintScreen করে Paint এ পেস্ট করে সেভ করুন)
  ৩) Visual Diagnose পেজে ছবিটা বাছাই করুন — ছবির প্রিভিউ দেখাবে
  ৪) "Analyze Screenshot" চাপুন
  ৫) কিছুক্ষণ পর (llava ধীরগতির হতে পারে) ফলাফল দেখাবে:
     Root Cause, Evidence, Solution, Steps — সব পড়ে নিন

Docker দিয়ে চালালে:
      docker compose down
      docker compose up -d --build

জেনে রাখুন
------------------------------------------------------------
- Visual Diagnose এর ফলাফল এখনো History তে সেভ হয় না
  (টেক্সট ডায়াগনোসিস হয় সেভ হয়)। এটা পরের কোনো জিপে যুক্ত হবে।
- বড় স্ক্রিনশট (১০ MB এর বেশি) দিলে error আসবে — ছোট করে নিন।
- প্রথমবার বিশ্লেষণ ধীর লাগতে পারে (মডেল প্রথমবার লোড হয়)।
- কোনো সমস্যা হলে ব্যাকআপ থেকে frontend/src ফেরত এনে আমাকে
  error লেখাটা জানান।

পরের সংশোধনী (জিপ ৪): কোড ফিক্স এজেন্টের UI (কাজ ২) — ভাঙা কোড
পেস্ট করলে AI ঠিক করে দেবে। ব্যাকএন্ডে তৈরি আছে, UI বাকি।
