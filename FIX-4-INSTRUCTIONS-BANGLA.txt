============================================================
TechPilot AI - সংশোধনী ৪: কোড ফিক্স এজেন্ট UI (কাজ ২)
============================================================

এই জিপে যা আছে (৫টি ফাইল + এই নির্দেশনা) — সবই frontend এর:
------------------------------------------------------------
1) src/pages/CodeFix.jsx                -> নতুন পেজ: ভাঙা কোড + error
                                           দিলে AI ঠিক করে দেয় (নতুন ফাইল)
2) src/components/CodeFixResultView.jsx -> ফলাফল দেখানোর কম্পোনেন্ট,
                                           ডার্ক কোড ব্লক + Copy Code বাটন
                                           (নতুন ফাইল)
3) src/App.jsx                          -> নতুন পেজের রাউট (/code-fix)
4) src/components/Layout.jsx            -> সাইডবারে নতুন লিংক "Code Fix"
5) src/App.css                          -> কোড ব্লক ও বাটনের স্টাইল

ব্যাকএন্ডে কোনো পরিবর্তন নেই — ব্যাকএন্ড রিস্টার্ট করা লাগবে না।

এর আগে কী সমস্যা ছিল?
------------------------------------------------------------
ব্যাকএন্ডে কোড ফিক্স এজেন্ট (/api/agents/code) পুরো তৈরি ছিল, কিন্তু
ওয়েবসাইটে ব্যবহার করার কোনো পেজ ছিল না — ফিচারটা লুকানো ছিল।

ইনস্টল করার নিয়ম
------------------------------------------------------------
ধাপ ১: ব্যাকআপ নিন (পুরো প্রজেক্ট ফোল্ডারের কপি)।
ধাপ ২: জিপ আনজিপ করে ভেতরের "frontend" ফোল্ডার প্রজেক্ট রুটে
        কপি-পেস্ট করুন -> "Replace the files" বাছুন।
ধাপ ৩: ফ্রন্টএন্ড চালু থাকলে বন্ধ করে আবার চালু করুন:
      cd E:\techpilot-ai\techpilot-ai\frontend
      npm run dev

চালানো ও টেস্ট করার নিয়ম
------------------------------------------------------------
টেস্ট ১ (নতুন পেজ):
  লগইন করে সাইডবারে দেখুন — "Code Fix" লিংক আছে কিনা
  (Visual Diagnose এর নিচে)। ক্লিক করলে কোড ফিক্স পেজ আসবে।

টেস্ট ২ (খালি ফিল্ড):
  কিছু না লিখে সাবমিট করা যাবে না (ব্রাউজার আটকে দেবে)।

টেস্ট ৩ (আসল AI ফিক্স):
  ১) Ollama চালু আছে কিনা নিশ্চিত করুন (qwen3.5:0.8b মডেলটা
     আপনার আগেই আছে, নতুন কিছু ডাউনলোড লাগবে না)
  ২) Code Fix পেজে লিখুন:
     Broken code:    function add(a, b) { retrun a + b; }
     Error message:  SyntaxError: Unexpected token
  ৩) "Fix My Code" চাপুন
  ৪) ফলাফলে দেখবেন: Problem, Explanation, ডার্ক বক্সে ঠিক করা কোড,
     Changes Made, Verification
  ৫) "Copy Code" বাটন চেপে ঠিক করা কোড কপি করে নিজের এডিটরে
     পেস্ট করে চালিয়ে দেখুন — কাজ করবে!

Docker দিয়ে চালালে:
      docker compose down
      docker compose up -d --build

জেনে রাখুন
------------------------------------------------------------
- AI ছোট টাইপো/সিনট্যাক্স/লজিক bug ভালো ধরে; বড় প্রজেক্টের অনেক
  ফাইলের সমস্যা একবারে ঠিক করতে পারে না — ছোট অংশ করে দিন।
- কোড পেস্ট করার সময় আসল পাসওয়ার্ড/সিক্রেট মুছে দিন!
- কোনো সমস্যা হলে ব্যাকআপ থেকে frontend/src ফেরত এনে আমাকে
  error লেখাটা জানান।

পরের সংশোধনী (জিপ ৫): ভেরিফিকেশন-ডায়াগনোসিস লিংকিং (কাজ ৫) —
"Worked / Didn't Work" রেটিং এখন কোন ডায়াগনোসিসের সাথে ছিল তা
সেভ হয় না; সেটা ঠিক করা হবে (ডাটাবেস মাইগ্রেশন লাগবে)।
