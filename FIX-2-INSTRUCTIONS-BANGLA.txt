(কাজ ৪: ডায়াগনোসিস এজেন্টে RAG যুক্ত করা)
============================================================

এই জিপে যা আছে (৪টি ফাইল + এই নির্দেশনা):
------------------------------------------------------------
1) backend/src/services/rag/retrieve.js
   -> নতুন ফাংশন: সমস্যার সাথে মিলিয়ে নলেজ বেস থেকে সবচেয়ে
      প্রাসঙ্গিক ৩টি অংশ খোঁজে, নিরাপদে (কখনো error দেয় না)
2) backend/src/agents/baseJsonAgent.js
   -> সব ডায়াগনোসিস এজেন্ট (troubleshooting/database/code/devops)
      এখন উত্তর দেওয়ার আগে নলেজ বেসের অংশগুলো প্রম্পটে দেখে নেয়
3) frontend/src/components/DiagnosisResultView.jsx
   -> ফলাফলে নতুন নীল বক্স: "Knowledge Base Used" — কোন কোন
      ডকুমেন্ট AI ব্যবহার করেছে তা দেখায়
4) frontend/src/App.css
   -> নতুন বক্সের স্টাইল

এর আগে কী সমস্যা ছিল?
------------------------------------------------------------
আপনি Knowledge পেজে ডকুমেন্ট যোগ করলেও AI ডায়াগনোসিসের সময়
ওগুলো পড়তই না। নলেজ বেস শুধু Knowledge পেজের সার্চে কাজ করত।
এখন AI প্রতিটি ডায়াগনোসিসের আগে আপনার নলেজ বেস খুঁজে দেখে।

ইনস্টল করার নিয়ম (ধাপে ধাপে)
------------------------------------------------------------
ধাপ ১: পুরো প্রজেক্ট ফোল্ডারের একটা কপি ব্যাকআপ রাখুন।
        (আগের জিপের ফাইলগুলোতে আপনি নিজে কিছু বদলে থাকলে
         ব্যাকআপ থেকে মিলিয়ে নেবেন)

ধাপ ২: এই জিপ আনজিপ করুন। ভেতরের "backend" ও "frontend" ফোল্ডার
        আপনার প্রজেক্ট রুটে কপি-পেস্ট করুন
        (যেমন E:\techpilot-ai\techpilot-ai)
        -> "Replace the files in the destination" বাছুন।
        মনে রাখবেন: ভেতরে নতুন করে node_modules নেই, শুধু ৪টি
        ফাইল রিপ্লেস হবে — কিছু ইনস্টল করা লাগবে না।

ধাপ ৩: ব্যাকএন্ড ও ফ্রন্টএন্ড চালু থাকলে দুটোই বন্ধ করুন (Ctrl+C)।

চালানো ও টেস্ট করার নিয়ম
------------------------------------------------------------
টেস্ট ১ (নলেজ বেস ছাড়াও কাজ করে — নিরাপত্তা পরীক্ষা):
  আগের মতোই চালু করুন:
      backend:  cd E:\techpilot-ai\techpilot-ai\backend  → npm run dev
      frontend: cd E:\techpilot-ai\techpilot-ai\frontend → npm run dev

  Diagnose পেজে যেকোনো সমস্যা লিখে Analyze চাপুন।
  আগের মতোই উত্তর আসবে — কোনো নীল বক্স থাকবে না, কোনো error নেই।
  (এটা প্রমাণ করে: নলেজ বেস খালি থাকলেও AI আটকায় না)

টেস্ট ২ (আসল RAG পরীক্ষা):
  ১) Ollama চালু আছে কিনা নিশ্চিত করুন। টার্মিনালে:  ollama list
     তালিকায় nomic-embed-text না থাকলে:  ollama pull nomic-embed-text
  ২) ওয়েবসাইটে Knowledge পেজে গিয়ে একটা ডকুমেন্ট যোগ করুন, যেমন:
     Title: PostgreSQL Troubleshooting Guide
     Category: database
     Content: যদি PostgreSQL connection refused দেখায়: প্রথমে services.msc
     খুলে postgresql সার্ভিস চালু আছে কিনা দেখুন। তারপর netstat -an দিয়ে
     চেক করুন পোর্ট 5432 লিসেন করছে কিনা। pg_hba.conf এ হোস্ট অনুমতি আছে কিনা দেখুন।
  ৩) Diagnose পেজে সম্পর্কিত সমস্যা লিখুন, যেমন:
     "PostgreSQL connection refused on port 5432"
  ৪) Analyze চাপুন। ফলাফলের নিচে নীল "Knowledge Base Used" বক্সে
     আপনার ডকুমেন্টের নাম দেখতে পাবেন — এটাই প্রমাণ যে RAG কাজ করছে!
  ৫) আরও ভালোভাবে দেখতে: উত্তরের solution/steps এ আপনার ডকুমেন্টের
     পরামর্শের (যেমন pg_hba.conf / netstat) উল্লেখ আসছে কিনা খেয়াল করুন।

Docker দিয়ে চালালে:
      docker compose down
      docker compose up -d --build
  (ফ্রন্টএন্ড Docker ইমেজ নতুন করে বিল্ড হবে বলে --build জরুরি)

সমস্যা হলে কী দেখবেন
------------------------------------------------------------
- বক্স দেখা যাচ্ছে না কিন্তু উত্তর আসছে:
  নলেজ বেস খালি, বা সমস্যার সাথে ডকুমেন্ট মিলছে না, বা
  nomic-embed-text মডেল নেই। ব্যাকএন্ড টার্মিনালে "Knowledge context
  unavailable" লেখা দেখলে এই কারণেই।
- অন্য কোনো error: ব্যাকআপ ফোল্ডার থেকে ৪টি ফাইল ফেরত এনে আমাকে
  error লেখাটা পাঠান।
