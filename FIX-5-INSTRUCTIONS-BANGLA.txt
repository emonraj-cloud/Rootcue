============================================================
TechPilot AI - সংশোধনী ৫: ভেরিফিকেশন-ডায়াগনোসিস লিংকিং (কাজ ৫)
============================================================

এই জিপে যা আছে (৪টি ফাইল + এই নির্দেশনা):
------------------------------------------------------------
1) backend/src/controllers/verificationController.js
   -> "Worked / Didn't Work" রেটিং এখন কোন ডায়াগনোসিসের
      সাথে ছিল তা ডাটাবেসে সেভ হয় (এটা ব্যাকএন্ড ফাইল!)
2) frontend/src/pages/Diagnose.jsx
   -> রেটিং দেওয়ার সময় ডায়াগনোসিসের ID সাথে পাঠানো হয়
3) frontend/src/pages/DiagnosisDetail.jsx
   -> History-তে পুরনো ডায়াগনোসিস খুললে তার সাথে লিংক করা
      সব রেটিং দেখা যাবে ("Verification History" সেকশন)
4) frontend/src/App.css -> নতুন সেকশনের স্টাইল

এর আগে কী সমস্যা ছিল?
------------------------------------------------------------
আপনি কোনো সমাধানে "Worked" বা "Didn't Work" চাপলে সেটা সেভ
হতো, কিন্তু কোন ডায়াগনোসিসের সমাধান সেটা ছিল তা জমা হতো না।
ফলে History-তে গিয়ে দেখা যেত না কোন ফিক্স কাজ করেছিল।
ডাটাবেসে এর জন্য জায়গা (migration 008) আগে থেকেই ছিল —
এখন সেটা ব্যবহার হচ্ছে।

ইনস্টল করার নিয়ম (ধাপগুলো ক্রম অনুযায়ী করুন)
------------------------------------------------------------
ধাপ ১: ব্যাকআপ নিন (পুরো প্রজেক্ট ফোল্ডারের কপি)।

ধাপ ২: জিপ আনজিপ করে ভেতরের "backend" ও "frontend" দুটো
        ফোল্ডারই প্রজেক্ট রুটে (techpilot-ai ফোল্ডারে)
        কপি-পেস্ট করুন -> "Replace the files" বাছুন।

ধাপ ৩: ডাটাবেস মাইগ্রেশন চালান (খুব জরুরি! একবারই করতে হবে):
        Command Prompt খুলে লিখুন:
      cd E:\techpilot-ai\techpilot-ai\backend
      npm run migrate
   দেখবেন 008 নম্বর মাইগ্রেশন applied হলো (বা আগেই
   applied ছিল — দুটোই ঠিক আছে)।

ধাপ ৪: ব্যাকএন্ড ও ফ্রন্টএন্ড দুটোই বন্ধ করে আবার চালু করুন:
      ব্যাকএন্ড:   cd E:\techpilot-ai\techpilot-ai\backend
                  npm run dev
      ফ্রন্টএন্ড:  নতুন Command Prompt খুলে:
                  cd E:\techpilot-ai\techpilot-ai\frontend
                  npm run dev

Docker দিয়ে চালালে:
      docker compose down
      docker compose up -d --build
      docker compose exec backend npm run migrate

চালানো ও টেস্ট করার নিয়ম
------------------------------------------------------------
টেস্ট ১ (রেটিং + লিংক সেভ):
  ১) লগইন করে Diagnose পেজে একটা সমস্যা লিখে Analyze করুন
  ২) ফলাফল আসলে "Did this solution work?" বক্সে নোট লিখে
     "Worked" চাপুন
  ৩) সবুজ লেখায় দেখবেন: "Marked as success and linked to
     this diagnosis" — লিংক হয়েছে!

টেস্ট ২ (History-তে রেটিং দেখা):
  ১) সাইডবার থেকে History তে যান, ওই ডায়াগনোসিসটা খুলুন
  ২) নিচে "Verification History" সেকশনে আপনার রেটিং
     (success ট্যাগ) আর নোট দেখতে পাবেন

টেস্ট ৩ (মাইগ্রেশন ভুলে গেলে):
  ধাপ ৩ না করে রেটিং দিলে এরর দেখাবে যাতে লেখা থাকবে
  "npm run migrate" — তখন শুধু ধাপ ৩ করে আবার চেষ্টা করুন।

জেনে রাখুন
------------------------------------------------------------
- পুরনো রেটিংগুলোর সাথে কোনো ডায়াগনোসিস লিংক করা ছিল না,
  তাই সেগুলো History-তে আগের মতোই (লিংক ছাড়া) দেখাবে।
- রেটিং সবসময় আপনার নিজের ডায়াগনোসিসের সাথেই লিংক হয় —
  অন্য ইউজারের ডায়াগনোসিসে ঢোকানো যায় না (সুরক্ষা যাচাই
  ব্যাকএন্ডে করা হয়)।
- কোনো সমস্যা হলে ব্যাকআপ থেকে ফাইলগুলো ফেরত এনে আমাকে
  error লেখাটা জানান।

পরের সংশোধনী (জিপ ৬): নলেজ বেস ইউজার-স্কোপিং (কাজ ৬) —
এখন এক ইউজারের আপলোড করা জ্ঞান সবাই দেখে পায়; সেটা
প্রতি-ইউজার করা হবে (ডাটাবেস মাইগ্রেশন লাগবে)।
