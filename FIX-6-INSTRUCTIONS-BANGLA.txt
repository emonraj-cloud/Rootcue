  src/services/rag/ingestDocument.js      -> user_id সহ সেভ

  src/App.css              -> ব্যাজের স্টাইল

এর আগে কী সমস্যা ছিল?
------------------------------------------------------------
আপনি Knowledge Base-এ যা আপলোড করতেন, সেটা সাইটের সব
ইউজার দেখতে পাত এবং সবার ডায়াগনোসিসে AI সেটা ব্যবহার করত।
এখন: আপনার আপলোড শুধু আপনার দেখা যাবে, শুধু আপনার
ডায়াগনোসিসে ব্যবহৃত হবে।

আগে থেকে জমা ডকুমেন্টগুলোর মালিক নেই — তাই সেগুলো
"shared" থাকবে (সবাই দেখবে)। Knowledge পেজে সেগুলোর পাশে
ধূসর "shared" ব্যাজ দেখবেন।

ইনস্টল করার নিয়ম (ক্রম অনুযায়ী করুন)
------------------------------------------------------------
ধাপ ১: ব্যাকআপ নিন (পুরো প্রজেক্ট ফোল্ডারের কপি)।

ধাপ ২: জিপ আনজিপ করে ভেতরের "backend" ও "frontend" দুটো
        ফোল্ডারই প্রজেক্ট রুটে কপি-পেস্ট করুন ->
        "Replace the files" বাছুন।

ধাপ ৩: ডাটাবেস মাইগ্রেশন চালান (খুব জরুরি!):
      cd E:\techpilot-ai\techpilot-ai\backend
      npm run migrate
   দেখবেন 009 নম্বর মাইগ্রেশন applied হলো।

ধাপ ৪: ব্যাকএন্ড রিস্টার্ট করুন (চালু থাকলে Ctrl+C দিয়ে বন্ধ
        করে আবার):  cd backend থেকে  npm run dev
        ফ্রন্টএন্ডও রিস্টার্ট করুন।

Docker দিয়ে চালালে:
      docker compose down
      docker compose up -d --build
      docker compose exec backend npm run migrate

চালানো ও টেস্ট করার নিয়ম
------------------------------------------------------------
টেস্ট ১ (আপলোড আপনার নামে):
  ১) লগইন করে Knowledge Base পেজে একটা ডকুমেন্ট যোগ করুন
  ২) লিস্টে সেটা দেখাবে — পাশে "shared" ব্যাজ নেই

টেস্ট ২ (পুরনো ডকুমেন্ট shared):
  আগে থেকে জমা ডকুমেন্টগুলোর পাশে ধূসর "shared" ব্যাজ দেখবেন

টেস্ট ৩ (অন্য ইউজার দেখবে না) — ২টি অ্যাকাউন্ট থাকলে:
  ১) অ্যাকাউন্ট A দিয়ে একটা ডকুমেন্ট আপলোড করুন
  ২) লগআউট করে অ্যাকাউন্ট B-তে ঢুকুন
  ৩) B-র Knowledge লিস্টে A-র ডকুমেন্ট দেখা যাবে না
     (শুধু B-র নিজের + shared গুলো)
  ৪) B দিয়ে Search করলেও A-র ডকুমেন্টের লেখা আসবে না

টেস্ট ৪ (মাইগ্রেশন ভুলে গেলে):
  ধাপ ৩ না করলে ডকুমেন্ট যোগ করতে এরর দেখাবে যাতে লেখা
  "npm run migrate" — তখন শুধু ধাপ ৩ করে আবার চেষ্টা করুন।

জেনে রাখুন
------------------------------------------------------------
- আপনার আপলোড করা জ্ঞান এখন শুধু আপনার ডায়াগনোসিসে AI-এর
  কাছে যাবে — অন্য ইউজারের ডায়াগনোসিসে নয়।
- "shared" ডকুমেন্ট মানে: মালিক নেই, সবাই দেখতে পায়।
- কোনো সমস্যা হলে ব্যাকআপ থেকে ফাইলগুলো ফেরত এনে আমাকে
  error লেখাটা জানান।

পরের সংশোধনী (জিপ ৭): ফাইল আপলোড থেকে জ্ঞান তৈরি (কাজ ৭) —
backend-এ আছে এমন /api/upload দিয়ে টেক্সট ফাইল আপলোড করে
সরাসরি Knowledge Base-এ ঢোকানো যাবে (ফাইল থেকে জ্ঞান)।
